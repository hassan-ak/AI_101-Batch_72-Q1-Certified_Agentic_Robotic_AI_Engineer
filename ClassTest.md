### **Beginner-Level Scenario-Based Python Practice**

**Title:** *Simple Grocery Inventory System*

**Scenario:**

You are working at a small grocery shop. Your job is to help keep track of some items using Python. Each item has:

* A name (e.g., "Milk")
* Quantity (e.g., 5)
* Price per unit (e.g., 2.5)

You will write a program that:

1. Adds a few items to the inventory.
2. Shows all the items with their quantity and price.
3. Shows the total value of the inventory.

**Instructions:**

* Use lists or dictionaries to store item information.
* Get item details using `input()`.
* Use a loop to allow the user to enter 3 items.
* Then display all items and the total inventory value.

---
